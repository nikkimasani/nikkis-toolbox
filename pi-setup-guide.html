Start here first

Raspberry Pi 5 setup, from unopened box to SSH.

This walkthrough assumes you are brand new to Raspberry Pi. It covers downloading Raspberry Pi Imager, writing the operating system, enabling SSH before first boot, Windows Command Prompt and PowerShell, macOS/Linux Terminal, optional Ubuntu, updates, software installs, remote access, and verification.

1

Gather the exact hardware before starting

Do not assemble the shadow box or connect the DSI screen yet. First prove the Pi works normally.

  1. Set out the Raspberry Pi 5 4 GB, 128 GB microSD card, UANTIN card reader, 45W USB-C Pi power adapter, micro-HDMI cable, and a regular HDMI monitor or TV.
  2. Keep the Pi 5 case nearby, but if installing it makes access harder, you can first boot the bare Pi on a nonconductive surface.
  3. Do not place the Pi on carpet, metal, foil, or a conductive anti-static bag while powered.
  4. Leave the 7-inch DSI display disconnected until the operating system, networking, and SSH have been verified.
✓ Done when: you have the Pi, microSD, reader, monitor cable, keyboard/mouse if available, and power adapter in front of you.
2

Download and install Raspberry Pi Imager

Raspberry Pi Imager writes the operating system onto the microSD card.

  1. On your Windows computer, open a browser and go to the official Raspberry Pi software page.
  2. Download Raspberry Pi Imager for Windows.
  3. Open the downloaded installer. Approve the Windows User Account Control prompt if it appears.
  4. Finish installation, then launch Raspberry Pi Imager from Start.
Optional Windows verificationPowerShell
Get-Command rpi-imager -ErrorAction SilentlyContinue
  1. Download Raspberry Pi Imager for macOS from the official Raspberry Pi software page.
  2. Open the downloaded package or DMG and move/install Raspberry Pi Imager as prompted.
  3. If macOS blocks the first launch, use System Settings → Privacy & Security and approve the app.
  1. On Ubuntu, you can install Raspberry Pi Imager from the package manager if available, or use the official AppImage/package.
Ubuntu package installTerminal
sudo apt update
sudo apt install -y rpi-imager
rpi-imager

If you want Ubuntu on the Raspberry Pi itself, you still use Raspberry Pi Imager on another computer. Choose Ubuntu Desktop 64-bit or Ubuntu Server 64-bit in the OS picker instead of Raspberry Pi OS.

✓ Done when: Raspberry Pi Imager opens and shows the Device, Operating System, and Storage choices.
3

Insert the microSD card and identify it carefully

The next step erases the selected storage device, so verify capacity before writing.

  1. Insert the SanDisk 128 GB microSD into the SD/microSD card reader.
  2. Plug the card reader into your computer.
  3. Wait 10 to 20 seconds for the operating system to detect it.
  4. In Raspberry Pi Imager, choose Raspberry Pi 5 as the device.
  5. Choose Raspberry Pi OS (64-bit) with Desktop for the easiest first-time experience.
  6. Select the 128 GB microSD as Storage. Compare the capacity so you do not erase another drive.
⚠ The Write action erases the selected disk. Stop if you are not certain which drive is the microSD card.
4

Preconfigure Wi-Fi, username, hostname, and SSH

This is the important part that many short guides skip. Configure remote access before the first boot.

  1. Open the OS customization settings in Raspberry Pi Imager when prompted.
  2. Set hostname to nikkipi. Your Pi should later answer as nikkipi.local.
  3. Create your Raspberry Pi username and a strong password. Write the username down because SSH requires it.
  4. Enter your home Wi-Fi SSID exactly, including capitalization.
  5. Enter the Wi-Fi password and select the correct Wi-Fi country.
  6. Set locale/time zone to America/Chicago if that matches your location.
  7. Enable SSH. For the easiest first setup, choose password authentication. You can switch to SSH keys afterward.
  8. Save the customization settings.
✓ Done when: Imager shows your hostname, user, Wi-Fi configuration, and SSH as enabled.
5

Write Raspberry Pi OS to the card

Let Imager write and verify the operating system completely.

  1. Click Write.
  2. Approve the operating-system permission prompt.
  3. Wait while Imager writes the image. Do not unplug the reader.
  4. Let the verification phase finish. Verification catches bad writes and card problems.
  5. When Imager says the card can be removed, eject it cleanly from the operating system.
  6. Remove the microSD card from the reader.
✓ Done when: Raspberry Pi Imager reports a successful write and verification.
6

Install the microSD in the Raspberry Pi 5

Power stays disconnected until all first-boot cables are attached.

  1. Confirm the USB-C power cable is not connected to the Pi.
  2. Insert the microSD card into the Raspberry Pi 5 microSD slot. Do not force it.
  3. Connect the micro-HDMI cable from the Pi to your monitor or TV.
  4. If you have a USB keyboard and mouse, connect them now. If not, SSH can still be used if Wi-Fi customization succeeds.
  5. Connect Ethernet optionally if you want the simplest first network test.
⚠ Do not connect or disconnect the DSI ribbon while the Pi is powered.
7

Power on and wait through the first boot

The first boot takes longer than normal because the Pi expands and initializes the filesystem.

  1. Turn on the monitor and select its correct HDMI input.
  2. Connect the 45W USB-C adapter to the Pi.
  3. Wait. The first boot can take several minutes.
  4. If the desktop appears, allow Raspberry Pi OS to finish any welcome prompts.
  5. Confirm the Wi-Fi icon shows a connection.
  6. If the screen stays blank, recheck the HDMI port/cable and confirm the microSD write completed successfully.
✓ Done when: you see the Raspberry Pi desktop and the Pi has joined your network.

9

Connect over SSH for the first time

SSH lets you control the Pi from your normal computer without typing on the Pi itself.

  1. Open Windows Terminal, PowerShell, or Command Prompt.
  2. Replace YOUR_USERNAME with the username you created in Raspberry Pi Imager.
SSH using hostnamePowerShell or Command Prompt
ssh YOUR_USERNAME@nikkipi.local
SSH into PiTerminal
ssh YOUR_USERNAME@nikkipi.local
SSH into PiTerminal
ssh YOUR_USERNAME@nikkipi.local

From another computer, SSH to Ubuntu on the Pi exactly the same way. Ubuntu may use the hostname you configured in Imager instead of nikkipi if you chose a different name.

  1. The first connection asks whether you trust the host fingerprint. Type yes and press Enter.
  2. Enter the Raspberry Pi password. The password does not visibly type on screen. That is normal.
  3. After login, your prompt should change to something similar to username@nikkipi:~ $.
✓ Done when: your computer's terminal shows a shell prompt on nikkipi.
10

If SSH fails, diagnose it systematically

Do not keep retrying the same command without checking which part failed.

“Could not resolve hostname”Use the Pi's IP address instead of nikkipi.local.
“Connection refused”SSH is probably not enabled or the service is not running.
“Permission denied”Check username and password.
TimeoutCheck Wi-Fi, VLAN/guest network isolation, or firewall.
Check SSH service on the PiPi Terminal
sudo systemctl status ssh
sudo systemctl enable --now ssh
Find Pi IPPi Terminal
hostname -I

Update the operating system completely

Do this before installing project software.

Raspberry Pi OS or Ubuntu updateSSH or Pi Terminal
sudo apt update
sudo apt full-upgrade -y
sudo reboot
  1. After running reboot, the SSH connection closes. That is expected.
  2. Wait about 60 to 90 seconds.
  3. Reconnect using the same SSH command.
✓ Done when: the Pi reboots and you can SSH back in.

Set up SSH keys so you do not type the password every time

Optional, but recommended once password SSH works.

Create key on WindowsPowerShell

Windows does not always include ssh-copy-id. Copy the printed public key, SSH into the Pi, then append it to ~/.ssh/authorized_keys using the commands below.

17

Shut down before connecting the 7-inch DSI display

Now that the Pi is proven, move to your touchscreen hardware.

Safe shutdownPi Terminal / SSH
sudo shutdown -h now
  1. Wait until activity has stopped and the system is fully shut down.
  2. Disconnect USB-C power physically.
  3. Connect the Pi 5-compatible DSI ribbon cable to the Pi and display with the correct contact orientation for the connectors.
  4. Lock the connector tabs squarely.
  5. Route the ribbon in a broad curve without a crease.
  6. Reconnect power and verify display and touch before mounting anything.
⚠ Never insert or remove the DSI cable while the Pi is powered.
18

Final baseline test before starting a project

This checkpoint separates OS/setup problems from project-specific problems.

  1. Reboot the Pi with the 7-inch display connected.
  2. Confirm the desktop appears on the touchscreen.
  3. Touch all four screen corners and verify pointer accuracy.
  4. Reconnect over SSH from your computer.
  5. Run the system verification bundle again.
  6. Open Chromium and load a normal website.
  7. Only after all of these pass should you start the Smart Mirror, Dashboard, Electronics Lab, or Cyberdeck guide.
✓ Setup complete when: display, touch, Wi-Fi, SSH, browser, package tools, and temperature checks all work.
