Start here first

Raspberry Pi 5 setup, visually and step by step.

Follow this before any project. It covers Raspberry Pi Imager, microSD preparation, Wi-Fi, SSH, Windows Command Prompt and PowerShell, macOS and Ubuntu terminals, updates, development tools, Node.js, DSI safety, and final verification.

OSRaspberry Pi OS 64-bit Desktop
StorageSanDisk 128 GB microSD
Hostnamenikkipi
GoalSSH + touchscreen ready
1

Gather the first-boot hardware

Prove the Pi works before connecting the DSI display or mounting anything.

  1. Set out the Raspberry Pi 5, 128 GB microSD, UANTIN reader, 45W USB-C adapter, micro-HDMI cable, monitor/TV, and keyboard/mouse if available.
  2. Keep the Pi on a dry, nonconductive surface.
  3. Leave the DSI touchscreen disconnected for now.
✓ Done when all first-boot parts are in front of you.
2

Install Raspberry Pi Imager

This is the official tool used to put Raspberry Pi OS on the microSD card.

  1. Open raspberrypi.com/software on your Windows computer.
  2. Download Raspberry Pi Imager for Windows.
  3. Run the installer, approve UAC, finish installation, then open Imager.
  1. Download Raspberry Pi Imager for macOS.
  2. Open the installer/DMG and install the app.
Ubuntu Terminal
sudo apt update
sudo apt install -y rpi-imager
rpi-imager

Use another computer to flash the Pi. If you specifically want Ubuntu on the Pi, choose Ubuntu Desktop 64-bit in Imager.

✓ Done when Imager opens.
3

Select Raspberry Pi 5, Raspberry Pi OS, and the 128 GB card

Verify storage carefully because writing erases the selected device.

  1. Insert the microSD into the reader and connect the reader to your computer.
  2. Choose Raspberry Pi 5.
  3. Choose Raspberry Pi OS (64-bit) with Desktop.
  4. Choose the 128 GB SanDisk card as Storage.
  5. Compare the capacity before continuing.
⚠ Write erases the selected storage device.
4

Configure hostname, user, Wi-Fi, and SSH

Do this before writing the card so remote access works on first boot.

  1. Set hostname to nikkipi.
  2. Create a username and strong password. Write the username down.
  3. Enter your Wi-Fi SSID and password exactly.
  4. Select the correct Wi-Fi country and time zone.
  5. Enable SSH and choose password authentication.
  6. Save the customization.
✓ Done when hostname, user, Wi-Fi, locale, and SSH are configured.
5

Write and verify the microSD

  1. Click Next/Write and approve the warning.
  2. Do not unplug the reader during writing.
  3. Let verification finish completely.
  4. Eject the card only after Imager says it is safe.
✓ Done when Imager reports successful write and verification.
6

Install the card and first-boot cables

  1. Keep USB-C power disconnected.
  2. Insert the microSD into the Pi 5.
  3. Connect micro-HDMI to a monitor.
  4. Connect keyboard/mouse if available.
  5. Ethernet is optional but useful for troubleshooting.
⚠ Keep the DSI display disconnected until the base setup passes.
7

Power on and wait for first boot

  1. Turn the monitor on and choose the correct HDMI input.
  2. Connect the 45W USB-C supply.
  3. Wait several minutes on first boot.
  4. Finish any desktop welcome prompts.
  5. Confirm Wi-Fi connects.
✓ Done when the Raspberry Pi desktop is visible and networked.
8

Find the Pi on your network

Command Prompt / PowerShell

Terminal

hostname

✓ Done when nikkipi.local resolves or you know the Pi's IPv4 address.
9

Make your first SSH connection

This is what a successful connection looks like.

Windows PowerShell, Command Prompt, macOS or Linux Terminal
ssh YOUR_USERNAME@nikkipi.local
  1. Replace YOUR_USERNAME with the username you created in Imager.
  2. Type yes when the fingerprint warning appears.
  3. Type your password. Nothing appears while typing the password; this is normal.
  4. Look for a prompt like YOUR_USERNAME@nikkipi:~ $.
✓ Done when the terminal prompt shows you are logged into nikkipi.
10

Troubleshoot SSH by error type

  1. Could not resolve hostname: use the Pi IP address.
  2. Connection refused: SSH may not be enabled.
  3. Permission denied: username or password is wrong.
  4. Timeout: check Wi-Fi and guest-network isolation.
Pi Terminal
sudo systemctl status ssh
sudo systemctl enable --now ssh
hostname -I

16

Record a system baseline

cat /proc/device-tree/model; echo

✓ Confirm model, storage, IP address, and temperature all look normal.
17

Shut down before connecting the DSI display

Safe shutdown
sudo shutdown -h now
  1. Wait for shutdown to finish.
  2. Physically unplug USB-C power.
  3. Connect the Pi 5-compatible DSI ribbon squarely at both ends.
  4. Lock the connector tabs.
  5. Keep a broad curve in the ribbon, not a crease.
⚠ Never insert or remove DSI while powered.
18

Final baseline test

  1. Boot with the 7-inch display connected.
  2. Confirm the desktop appears.
  3. Test touch in all four corners.
  4. SSH in again from your computer.
  5. Open Chromium and a normal website.
  6. Run the baseline commands again.
✓ Setup is complete when display, touch, Wi-Fi, SSH, browser, tools, and temperature all pass.
